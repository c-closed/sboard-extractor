Sboard 추출기 v1.4.7.7

Sboard 계약 데이터 자동 추출 프로그램입니다.

기능:
- Sboard 자동 로그인
- 수행사업 목록 자동 검색
- 계약 상세 정보 추출 (사업명, 공급가액, 총수금액, 잔액, 총외주액, 외주잔액)
- 추출 데이터를 팀장회의 취합.xlsx에 자동 기록
- 일시정지/다시시작 기능
- 자동 업데이트 (AutoUpdater.NET)

시스템 요구사항:
- Windows 10/11 (64비트)
- .NET 8 런타임 포함 (별도 설치 불필요)
- Microsoft Excel (xlsx 파일 읽기/쓰기 필요)

지원: https://github.com/c-closed/sboard-extractor
